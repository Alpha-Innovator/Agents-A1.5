How does the mouse brain encode different variables within a visual decision-making task?

A mouse sees a pattern, turns a wheel, then receives a reward or an error cue.

WHY THIS RESEARCH MATTERS

Revisit existing data. Generate testable new hypotheses.

The reanalysis shows that decoding measures for different task variables covary across mouse brain regions, and that this structure is associated with wheel-movement measures.

SeekBrain connects data reanalysis, statistical checks and anatomical mapping so researchers can trace the evidence and formulate testable hypotheses.

A TESTABLE NEXT QUESTION

What remains when movement is controlled?

If wheel direction and speed are matched in a new experiment, do some regions retain information specific to pattern location or feedback?

How to test it: control wheel movement in independent data and check whether the remaining information is stable.

This example hypothesis is a showcase interpretation of the saved results, to be tested in future experiments.
