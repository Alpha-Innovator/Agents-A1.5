02 / PARAMETER CHANGES
从参数变化，到谱图残差
背景与比例改变整体强度；晶胞调整反射位置；坐标调整结构因子。每次只开放选中的参数块。
当前结构与谱图都对应同一轮 accepted 参数。求解器由结构因子生成计算谱，再将计算谱与观测谱之差按标准差加权，得到 Rwp。
观测谱来自原始 XYE；计算谱使用冻结前向模型，在 CPU float64 上按 accepted 参数重绘。Rwp 数值始终取原始 NPU 运行记录。
参数初始当前 accepted
原子编号从 0 开始；atom.0 始终固定。坐标位移按初始晶格计算，不含晶胞变化引起的整体移动。本案例未开放 zero 与 profile。


03 / WHY A CLOSED LOOP
精修需要求解器，也需要决策
数值优化回答“这组变量怎么更新”。闭环还要回答“现在该动哪些变量、要不要继续，以及哪些结果应当保留”。
01 / PARAMETER COUPLING
先解释误差，再扩展自由度
比例、背景、晶胞、峰形和坐标会共同影响谱图。分阶段开放变量，让每个 trial 检验一个较小的假设，减少多个自由度同时补偿同一残差的歧义。
02 / FEEDBACK & BUDGET
停滞之后，重新分配试探
这条轨迹先调整晶胞长度，再检验角度；角度收益很小，系统保留上一状态并转向坐标。坐标块续跑停滞后，再将有限轮次用于其他原子。
03 / INDEPENDENT GATE
建议可以出错，状态必须受控
第 5 轮 reviewer 建议接受，但 Rwp 实际微增约 1.10×10⁻⁸ 个百分点。数值门禁拦截该建议，保留第 4 轮状态，曲线因此保持平台。
接受条件：物理约束有效，且 Rwp 下降达到数值门槛，再结合 reviewer 审查。Reviewer 也可以拒绝满足数值门槛的试探。下一轮始终从最后 accepted 状态出发。

数据来源、重绘方法与适用范围
来源：。本页选择 case_005，是因为它包含晶胞调整、坐标分块与两种拒绝机制，用于说明过程。这里只展示原始拟合轨迹，不对其他材料的下降幅度作推断。
协议 SHA256：。构建时校验协议、输入、九份状态快照和最终导出文件的哈希。下载的 JSON 包含完整参数、原始 Rwp、决策原文与快照哈希。
模型为单相 P1、满占位、零 ADP 的受限 Torch 精修器，使用 Marquardt/SVD 与批量有限差分。Rwp = 100 × √[Σ((yobs − ycalc)/σ)² / Σ(yobs/σ)²]，σ 为 XYE 第三列标准差。负计算强度点数也随轮次列于参数表；背景未施加逐点非负约束。
三维图按真实晶格和分数坐标绘制，不放大位移、不推断化学键；播放时仅在两个快照之间插值，便于观察。谱图为保留局部极值的显示抽样，Rwp 并未用抽样谱重算。所有曲线节点来自外层 accepted 快照，不能视为 160 个内层步数的连续轨迹。最后一轮结束原因为 trial_limit，最后一次求解为 no_descent_step。
